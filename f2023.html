Question 1 — Parameter passing and references

Trace functions that combine pass-by-value, pass-by-reference, and reference returns.

  • Actual and formal parameters, pass-by-value, reference variables
  • pass-by-reference, mixed parameter passing, return-by-value and return-by-reference

Question 2 — Recursion

Identify the behavior of recursive numeric and output functions.

  • Thinking recursively, recursive functions, base cases and recursive cases, infinite recursion

Question 3 — Scope

Trace shadowed variables, block scope, and reference aliases.

  • Identifier scope, function scope, block scope, identifiers with the same name
  • reference variables, pass-by-reference

Question 4 — Nested loops and printed shapes

Follow nested loop execution and output spacing.

  • while loops, for loops, nested loops

Question 5 — Two-dimensional arrays

Trace a matrix traversal and its row/column bounds.

  • multidimensional arrays, 2D array syntax, 2D array initialization, 2D array storage

Question 6 — Functions and return values

Define functions, validate arguments, and understand calls that modify an argument.

  • function definition syntax, formal and actual parameters, return types, return statement
  • pass-by-reference, reference parameter behavior

Question 7 — Structs and arrays of structs

Represent product records and update/search an inventory array.

  • structs as heterogeneous records, struct definition, accessing members
  • arrays of structures, functions operating on struct arrays, pass-by-reference, passing arrays to functions

Question 8 — C strings

Implement string operations by traversing and shifting characters in null-terminated arrays.

  • C strings as character arrays, null terminator, string length and traversal, C-string functions
